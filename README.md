# Social Media Platform - MERN

Portfolio-ready social media app using React/Vite, Node/Express, MongoDB/Mongoose and JWT.

## Run
Backend:
cd backend
copy .env.example .env
npm install
npm run dev

Frontend (new terminal):
cd frontend
npm install
npm run dev

Open http://localhost:5173

Features: register/login, JWT auth, profiles, posts, edit/delete, likes, comments, follow/unfollow, search people, notifications.
